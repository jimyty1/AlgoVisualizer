This project is about exploring algorithms and creating a pleasant visualization for educational purposes
I will be using C for the algorithms and backend with webassembly and a typescript frontend in order to explore these technologies further.
The aim is to get a better understanding of C and typescript in order to embark on more complex projects while making something educational and refreshing on algorithms, Data Structures and Search algos.
